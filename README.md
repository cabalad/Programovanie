# Programovanie – Študijný repozitár

Vítajte v oficiálnom študijnom repozitári pre predmet **Programovanie**. Tento repozitár je určený pre študentov stredných odborných škôl so zameraním na **mechatroniku, informatiku a elektrotechniku**.

Cieľom kurzu je prejsť od úplných základov verzionovania kódu a skriptovania až po pokročilé procedurálne, objektovo orientované a systémové programovanie pre operačný systém Windows.

---

## 🗺️ Študijná cesta (Roadmapa)

Kurz je štruktúrovaný do 5 nadväzujúcich modulov. Odporúčame prechádzať modulmi postupne:

| Modul | Názov modulu | Jazyk / Náplň | Popis |
| :--- | :--- | :--- | :--- |
| **00** | [`00_Git_a_Verzovanie/`](./00_Git_a_Verzovanie/) | Git, GitHub, CLI | Správa verzií kódu, práca s vetvami, GitHub workflow. |
| **01** | [`01_Python/`](./01_Python/) | Python 3 | Základy syntaxe, dátové štruktúry, algoritmizácia a skriptovanie. |
| **02** | [`02_C/`](./02_C/) | C (ANSI C / C99) | Základy procedurálneho programovania, práca s pamäťou a ukazovateľmi. |
| **03** | [`03_C++/`](./03_C++/) | C++ (C++11/14/17) | Objektovo orientované programovanie (OOP), triedy, dedičnosť, polymorfizmus. |
| **04** | [`04_Win32_API/`](./04_Win32_API/) | C / C++ / Win32 | Tvorba okenných (GUI) desktopových aplikácií pre OS Windows. |

## 🛠️ Požiadavky na softvér

Pre úspešné absolvovanie cvičení budete potrebovať nasledujúce nástroje:

1. **Git / Git Bash** – Pre správu verzií kódu ([git-scm.com](https://git-scm.com/))
2. **Code Editor / IDE**:
   - [Visual Studio Code](https://code.visualstudio.com/) (s rozšíreniami pre Python, C/C++)
   - [Microsoft Visual Studio Community](https://visualstudio.microsoft.com/) (s modulom *Desktop development with C++* pre Win32 API)
3. **Interpretre a kompilátory**:
   - **Python 3.x** ([python.org](https://www.python.org/))
   - **GCC / MinGW-w64** alebo MSVC pre kompiláciu C a C++

---

## 💡 Pokyny pre študentov

1. **Klonovanie repozitára**:
   ```bash
   git clone https://github.com/cabalad/Programovanie.git
   cd Programovanie
   ```
2. **Priebeh cvičení**:
   - V každom adresári nájdete podrobný `README.md` s teoretickým úvodom, cieľmi cvičenia a zoznamom úloh.
   - Vložte vypracované riešenia do príslušných podadresárov podľa pokynov vyučujúceho.
3. **Dodržiavanie štandardov**:
   - Dbyte na čistotu kódu, prehľadné odsadzovanie a zmysluplné pomenovanie premenných a funkcií.
